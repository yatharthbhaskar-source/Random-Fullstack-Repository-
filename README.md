# SkillUp - Online Learning and Skill Development Platform

SkillUp is an online learning platform designed to help students manage courses, track learning progress, and develop new skills.

## Features

- Student dashboard
- Course management
- Course progress tracking
- Lesson completion
- Achievements
- Student profile
- Settings
- Course search
- Responsive dark-themed interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Colab

## Project Objective

The objective of this project is to provide students with a simple platform where they can access learning courses and monitor their skill development.

## Project Type

Full Stack Web Application
